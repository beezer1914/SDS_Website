# Sigma Delta Sigma Chapter Website

Replacement for the WordPress site at https://sds1914.com. See README.md for setup and `docs/` for integration contracts.

## Repo map (read before adding files)

- **`/` (repo root) is the Next.js site.** Code is in `src/`. Do NOT scaffold another Next.js app (no `web/`, `frontend/`, etc.).
- **`studio/`** is the Sanity Studio, and it is the ONLY place the content schema lives (`studio/schemaTypes/`).
- `src/lib/content.ts`: all Sanity queries. With no `NEXT_PUBLIC_SANITY_PROJECT_ID`, it falls back to `src/data/sample-content.ts`.
- `src/lib/events.ts`: public events from the ChapterOps feed (`docs/chapterops-events-feed.md`).
- `src/sanity.types.ts`: generated by `cd studio && npm run typegen`. Don't edit by hand.
- `public/_redirects`: old WordPress URLs → new pages / ChapterOps.

## Architecture

- Static export (`output: "export"`) on Netlify. No server, no database. Sanity publishes and ChapterOps event changes trigger a Netlify build hook.
- Editors are non-technical and use the hosted Studio (sds1914.sanity.studio). Keep schema field names and descriptions plain-English.
- The Members area is ChapterOps (https://chapterops.bluecolumnsystems.com/). Don't build member features here.

## Commands

- `npm run build`: static export to `out/`
- `npm run check`: after a build, verifies old URLs still resolve or redirect
- `npm run lint`

## Guidelines

1. **Think before coding.** State assumptions. If uncertain, ask. Present alternatives instead of silently picking one. Push back if something simpler exists.
2. **Simplicity first.** Write the minimum code that solves the problem. No speculative features, single-use abstractions, or unrequested configurability.
3. **Surgical changes.** Touch only what the task needs. Match the existing style. Mention unrelated dead code rather than deleting it; remove only what your own change orphaned.
4. **Goal-driven execution.** Define a verifiable success check for each step (build passes, `npm run check` passes, a test reproduces the bug and then passes) and loop until it's met.
